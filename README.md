# PhotoSphere 360

서비스가 종료된 360도 사진 촬영 앱의 기능을 참고해 만든 독립형 Android 프로젝트입니다.

## 기능
- 후면 카메라로 여러 방향 사진 촬영
- 24장 촬영 가이드
- OpenCV Stitcher를 이용한 자동 파노라마 합성
- 결과 JPG를 Pictures/PhotoSphere360에 저장
- CameraX 기반 촬영

## 촬영 방법
1. 휴대폰을 대략 같은 높이에 유지합니다.
2. 한 장을 찍고 몸/휴대폰을 조금씩 회전합니다.
3. 인접한 사진끼리 30~50% 정도 겹치도록 촬영합니다.
4. 총 24장을 찍은 뒤 `360° 만들기`를 누릅니다.

## 주의
이 1차 버전은 Google Street View의 원본 소스나 네이티브 라이브러리를 추출하지 않습니다.
CameraX + OpenCV로 독립적으로 구현합니다.

현재 버전은 일반적인 파노라마 Stitcher를 사용합니다.
완전한 구형(천장/바닥까지 포함하는 360° Photo Sphere)으로 개선하려면
다음 단계에서 IMU(자이로/가속도계) 기반 촬영 가이드와
구면 투영/노출 보정/Zenith/Nadir 촬영을 추가하는 것이 좋습니다.
